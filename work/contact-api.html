API de gestion de contacts

Lecture et modification de contacts avec GraphQL

Une API qui expose des opérations de lecture et de modification sur des contacts, avec GraphQL plutôt qu’un REST classique.

Voir le code

01

Le point de départ

Ce projet est centré sur la couche backend : exposer des données de contacts de façon souple, en laissant le client demander exactement ce dont il a besoin.

02

Comment je l’ai construit

J’ai défini un schéma GraphQL, puis les opérations de lecture et de modification associées. Contrairement à une API REST avec plusieurs endpoints, le client formule sa requête et obtient la structure de réponse attendue — un exercice utile pour comprendre la modélisation d’un schéma et la validation des données.

03

Ce que ça apporte

Une API fonctionnelle pour consulter et modifier des contacts, avec un schéma explicite et des requêtes ciblées.

04

Les fonctions clés

  • Schéma GraphQL explicite
  • Opérations de lecture
  • Opérations de modification
  • Couche backend dédiée
