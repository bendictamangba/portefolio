Projet professionnel

IMMOBIZ

Plateforme Full-Stack de gestion immobilière

Un seul outil pour réunir les biens, les propriétaires, les locataires, les contrats, les annonces et les paiements — des informations qui vivaient jusque-là de façon dispersée.

Démo sur demande →

01

Le point de départ

La gestion d’un parc immobilier touche à plusieurs mondes : le propriétaire, le locataire, le contrat, l’annonce et le paiement. Quand chacun vit dans un fichier ou un outil différent, le suivi devient vite ingérable. IMMOBIZ part de ce constat : centraliser ces données dans une application web unique, avec des accès adaptés à chaque profil.

02

Comment je l’ai construit

J’ai structuré l’application en trois blocs : un socle de gestion des profils et des rôles, un référentiel des biens et des contrats, et un module dédié aux paiements. Le frontend Angular dialogue avec une API REST construite en Java avec Spring Boot, appuyée sur PostgreSQL. Les rôles ne sont pas décoratifs : ils déterminent ce que chaque utilisateur peut voir et modifier. L’ensemble est conteneurisé avec Docker pour garder le même environnement du développement jusqu’au déploiement.

03

Ce que ça apporte

Une application qui couvre tout le cycle : créer un bien, lui associer un propriétaire, gérer le locataire et le contrat, publier l’annonce, puis suivre les paiements. Chaque information reste rattachée à un seul et même outil.

04

Les fonctions clés

  • Gestion des profils et des rôles
  • Gestion du parc de biens immobiliers
  • Suivi des locataires et des contrats
  • API REST dédiée aux opérations métier
  • Intégration frontend / backend
  • Fonctionnalités liées aux paiements
