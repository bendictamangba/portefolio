IMMOBIZ

Full-Stack real estate management platform

One tool to bring together properties, owners, tenants, contracts, listings, and payments — information that used to live in scattered places.

Demo on request →

01

The starting point

Managing a property portfolio touches several worlds: the owner, the tenant, the contract, the listing, and the payment. When each one lives in a different file or tool, keeping track quickly becomes unmanageable. IMMOBIZ starts from that observation: centralize all this data in a single web application, with access tailored to each profile.

02

How I built it

I structured the application around three blocks: a foundation for profiles and roles, a reference dataset for properties and contracts, and a module dedicated to payments. The Angular frontend talks to a REST API built with Java and Spring Boot, backed by PostgreSQL. Roles are not decorative — they determine what each user can see and change. The whole stack is containerized with Docker to keep the same environment from development through deployment.

03

What it changes

An application covering the full cycle: create a property, assign an owner, manage the tenant and contract, publish the listing, then track payments. Every piece of information stays connected inside one tool.
