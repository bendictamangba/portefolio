03 Interface · Responsive · Integration
Client project

PamPam

Responsive showcase website for a shop in Lomé

A clear, mobile-first showcase with an interactive map and a direct line to WhatsApp.

Try it online ↗ View code

01

The starting point

A local shop needs to be found and contacted easily. For PamPam, the goal was simple: present the offer on every screen and make contact immediate, with no detour.

02

How I built it

I built a responsive showcase page in HTML and CSS, designed first for mobile where most visitors arrive. The interactive map gives the geographic landmark, and the WhatsApp link removes the form step: the visitor goes straight to the conversation.

03

What it changes

A site that works on mobile as well as desktop, with a very short path between discovering the shop and sending the first message.

04

Key features

  • Responsive layout
  • Interactive map
  • WhatsApp integration
  • Mobile-first journey
