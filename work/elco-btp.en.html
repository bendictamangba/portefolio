ELCO-BTP

Construction site management

Tracking and managing construction sites in a web application

A tool for tracking progress on construction sites and keeping field information in one place.

Demo on request →

01

The starting point

Tracking construction sites relies on information moving between the field and the office. The idea here is to bring it together in a web application so progress is easier to read.

02

How I built it

I developed the application with Laravel and Blade. The backend handles the tracking data, while Blade provides the screens for viewing and updating it — a deliberately simple stack for an internal tool.

03

What it changes

An application dedicated to tracking and managing construction sites, with a single access point for the information.

04

Key features

  • Construction progress tracking
  • Field information management
  • Screens for viewing and updating
  • Laravel backend
