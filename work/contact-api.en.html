Contact management API

Reading and updating contacts with GraphQL

An API that exposes read and update operations on contacts, using GraphQL instead of a conventional REST design.

View code

01

The starting point

This project focuses on the backend layer: exposing contact data in a flexible way, letting the client ask for exactly what it needs.

02

How I built it

I defined a GraphQL schema, then the matching read and update operations. Unlike a REST API with multiple endpoints, the client shapes its query and receives the expected response structure — a useful exercise in schema design and data validation.

03

What it changes

A working API for querying and updating contacts, with an explicit schema and targeted queries.

04

Key features

  • Explicit GraphQL schema
  • Read operations
  • Update operations
  • Dedicated backend layer
